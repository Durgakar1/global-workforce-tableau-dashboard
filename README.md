# Global Workforce Demographics Analysis Dashboard

## Overview
This project analyzes global workforce and population trends using Tableau dashboards built from United Nations and Census data.

The goal is to identify workforce distribution, dependency ratios, and demographic patterns across countries.

## Tools Used
- Tableau
- Data Cleaning
- Data Visualization
- Calculated Fields

## Key Insights
- Built 5+ interactive dashboards analyzing workforce trends across 190+ countries
- Identified workforce distribution and dependency ratio patterns
- Provided insights into aging populations and youth workforce regions
